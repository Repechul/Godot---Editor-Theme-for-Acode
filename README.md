# Godot - Editor Theme

A custom editor theme plugin for **Acode** that accurately replicates the default GDScript syntax highlighting and color scheme from Godot Engine's native script editor.

---

## 🌟 Features

- **Authentic Godot Color Palette**: Carefully crafted to mirror the exact GDScript color scheme used in the official Godot Engine script editor.
- **Dual Engine Support**: Full compatibility and seamless rendering across both **CodeMirror 6** (Acode's modern editor core) and **legacy Ace** editor backends.
- **Optimized Visual Clarity**: Designed for high contrast, legibility, and reduced eye strain during extended coding sessions on mobile screens.

---

## ⚙️ Recommended Setup & Compatibility

> [!IMPORTANT]
> **Best Paired With**: This theme is specifically tailored to work best alongside **[Godot - GDScript Support DX](https://github.com/Repechul/Acode-Plugin---Godot-GDScript-Support-DX)**.
> 
> Due to differences in how syntax tokens and scopes are parsed by various third-party Godot extensions, using this theme with other GDScript/Godot plugins for Acode may lead to mismatched colors or incomplete highlighting.

---

## 🚀 Installation

1. Open **Acode**.
2. Go to **Settings** > **Plugins**.
3. Search for **Godot - Editor Theme** (or install via `.zip` package / repository URL).
4. Tap **Install**.
5. Go to **Settings** > **Theme** > **Editor** and select **Godot - Editor Theme**.
